# Rent-Calculator
🚀 Introducing Rent Calculator: Simplify Expense Splitting for Shared Living! 🏠💸
📌 App Name: Rent Calculator
 🔍 Overview:
 Living with roommates? Splitting rent and utility bills can get tricky. Rent Calculator makes it effortless to divide monthly expenses fairly — no more confusion or manual math!

📝 Description:
 Built using Flask, along with HTML, CSS, and JavaScript, this app takes essential house expenses (rent, food, electricity, gas, water) and divides the total among all housemates. Whether you're living in a PG, flat, or shared house — this tool is made for you!

✨ Features:
 ✅ Expense Input Form – Add rent, utility bills, and number of people
 ✅ Per Person Share Calculation – Fair, fast, and accurate
 ✅ Responsive UI – Clean design with mobile-friendly interface
 ✅ Error Handling – Prevents invalid inputs for a smooth experience
 ✅ Easily Extensible – Future-ready: can add charts, login, or download options

🔥 Conclusion:
 The Rent Calculator brings clarity to shared living costs. It's quick, reliable, and made with real-life needs in mind.
